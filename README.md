# AI Quizipedia 🧠📚

An AI-powered full-stack educational web application that transforms Wikipedia articles into interactive quizzes for smarter learning. Built with FastAPI, React, and Google Gemini AI.

## 🚀 Features

### 🤖 AI-Powered Quiz Generation
- **Instant Quiz Creation**: Convert any Wikipedia article into an interactive quiz in seconds
- **Smart Content Analysis**: Extracts important sections, key concepts, and entities from Wikipedia content
- **Dynamic Question Generation**: Uses AI to generate meaningful quiz questions from article context
- **AI-Based Explanations**: Each answer includes an explanation to improve understanding

### 🎯 Interactive Quiz Experience
- **Timed Quiz Sessions**: Monitor how quickly you answer questions
- **Multiple Attempts**: Retry quizzes and improve your score
- **Instant Feedback**: Get correct answers immediately after submission
- **Question Navigation**: Smooth and user-friendly progress tracking through the quiz

### 📊 Performance Insights
- **Attempt History**: View previous quiz attempts and scores
- **Accuracy Tracking**: Analyze how well you're performing over time
- **Detailed Review Mode**: Compare your selected answers with correct ones
- **Learning Support**: Use explanations to strengthen weak areas

### 🎨 Modern User Interface
- **Responsive Design**: Optimized for desktop and mobile devices
- **Smooth Animations**: Enhanced UX with Framer Motion
- **Clean Dashboard**: Minimal, modern interface for a better learning experience

## 🛠️ Tech Stack

### Backend
- **FastAPI** - High-performance Python backend framework
- **PostgreSQL** - Relational database for storing quizzes and attempts
- **SQLAlchemy** - ORM for database interaction
- **Google Gemini AI** - AI model for generating quiz questions and explanations
- **BeautifulSoup4** - Parsing and extracting Wikipedia content
- **Pydantic** - Data validation and API schema management

### Frontend
- **React 18** - Component-based frontend library
- **Tailwind CSS** - Utility-first CSS framework
- **Framer Motion** - Smooth animations and transitions
- **Lucide React** - Modern icon set
- **Vite** - Fast frontend build tool

### Deployment & Infrastructure
- **NeonDB / PostgreSQL** - Cloud database
- **Vercel** - Frontend deployment
- **Render / Railway** - Backend deployment
- **Environment Variables** - Secure API and database configuration
